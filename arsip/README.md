# Arsip — Tahap Eksplorasi (Februari–Maret 2026)

Dokumen di folder ini berasal dari **tahap awal Ekosistem MAJA** (MAJA Digital Museum, Februari–Maret 2026),
termasuk kajian konsep token digital.

**Konsep token tersebut tidak lagi menjadi bagian dari Ekosistem MAJA.** Ekosistem MAJA kini berfokus pada transaksi dalam Rupiah melalui
payment gateway resmi (MajaCraft) dan sertifikat kepemilikan karya (MAJA Certified), tanpa unsur investasi.

Dokumen disimpan apa adanya sebagai catatan riwayat pengembangan, dan **tidak mencerminkan produk saat ini**.
